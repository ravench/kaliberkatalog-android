# Kaliberkatalog

Android app (Kotlin, Jetpack Compose, Android 8.0 and newer) that lists more than 700 calibres
with their dimensions, drawing and sources, from the shared
[calibre-data](https://github.com/ravench/calibre-data) catalogue. In German, English, French,
Italian and Spanish. A catalogue only: photo recognition and the 1:1 view stay with Kaliberfinder.
